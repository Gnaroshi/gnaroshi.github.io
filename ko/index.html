gnaroshi_vla

개발 중자세히 보기

서로 다른 VLA 모델을 한 실험 구조에서 설정하고 점검하며 비교하기 위한 작업 공간입니다.

남은 문제

  • 공통 어댑터 경계를 계속 다듬고 있습니다.
  • 모델 간 비교 결과는 검토한 실행이 쌓인 뒤 공개해야 합니다.

프로젝트 자료. 표시된 기본 동작 점검은 설명용 검증 자료이며 벤치마크 결과가 아닙니다.

예시 흐름

  1. 실행 조건 선택아키텍처와 방법, 환경, 실험 설정을 고릅니다.
  2. 작은 점검 실행설정 조합과 실행 연결이 맞는지 작은 실행으로 확인합니다.
  3. 매니페스트 확인해석된 설정과 환경 스냅샷을 살펴봅니다.
  4. 결과 위치 열기결과 경로를 확인하되 검토하지 않은 출력을 결론으로 다루지 않습니다.

표시된 기본 동작 점검은 설명용 검증 자료이며 벤치마크 결과가 아닙니다.

Gnaroshi Studio

개발 중자세히 보기

연구 기록 작성과 Git 체크포인트, 공개 미리보기, 명시적 발행을 한곳에서 다루는 로컬 macOS 작업 공간입니다.

남은 문제

  • 배포용 macOS 서명과 공증은 아직 설정하지 않았습니다.
  • 일부 관리 앱 연결은 배포 전 검토가 더 필요합니다.

프로젝트 자료. 화면의 제목과 앱 활동은 결정적으로 만든 데모 자료입니다.

예시 흐름

  1. 관리 앱 확인전달을 시작하기 전에 PaperFlow와 Arxiv Discovery를 쓸 수 있는지 봅니다.
  2. 후보 살펴보기설명용으로 표시된 소수의 논문 메타데이터를 확인합니다.
  3. 전달 미리보기PaperFlow로 넘길 공개 메타데이터 범위를 확인합니다.
  4. 체크포인트 확인보류 중인 로컬 변경을 보고 커밋이나 발행 전에 멈춥니다.

화면의 제목과 앱 활동은 결정적으로 만든 데모 자료입니다.

PaperFlow

로컬에서 사용 가능자세히 보기

Zotero를 읽기 전용으로 살피고 적용 전에 정리 계획을 검토하는 macOS 앱과 Python CLI입니다.

남은 문제

  • 최종 패키지 앱과 화면 모양 확인이 남았습니다.
  • 쓰기가 가능한 흐름은 계속 수동 검토가 필요합니다.

프로젝트 자료. 라이브러리 수와 변경 제안은 데모 자료이며 실제 Zotero 라이브러리를 열지 않았습니다.

예시 흐름

  1. 읽기 전용 스캔같은 읽기 전용 흐름으로 합성 라이브러리를 살펴봅니다.
  2. 계획 만들기적용하지 않고 컬렉션 이동과 중복 그룹을 준비합니다.
  3. 제안 확인쓰기가 가능한 동작 전에 범위와 항목을 확인합니다.
  4. 적용 전에 멈추기시연 모드에서는 적용을 끄고 명시적 경계를 유지합니다.

라이브러리 수와 변경 제안은 데모 자료이며 실제 Zotero 라이브러리를 열지 않았습니다.
