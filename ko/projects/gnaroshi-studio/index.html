Gnaroshi Studio

논문 기록과 글은 역할에 맞는 저장소에 둔 채, 검토와 체크포인트, 발행 단계를 하나의 로컬 앱에서 조정합니다.

개발 중macOS · CLI

한눈에 보기

대상
로컬 연구·글쓰기 작업 흐름을 관리하는 사람
주요 용도
작업을 검토하고 원본 저장소를 체크포인트한 뒤 공개 차이를 확인해 명시적으로 발행합니다.
제품 상태
개발 중
지원 환경
macOS · CLI

개요

Tauri 데스크톱 UI와 CLI 패키지가 같은 계약을 사용합니다. 저장, 커밋, 발행은 서로 다른 동작으로 유지됩니다.

사용 흐름

후보를 검토하는 흐름

발행하지 않은 채 보조 앱과 논문 후보 하나를 검토합니다.

  1. 1

    관리 앱 확인

    전달을 시작하기 전에 PaperFlow와 Arxiv Discovery를 쓸 수 있는지 봅니다.

  2. 2

    후보 살펴보기

    설명용으로 표시된 소수의 논문 메타데이터를 확인합니다.

  3. 3

    전달 미리보기

    PaperFlow로 넘길 공개 메타데이터 범위를 확인합니다.

  4. 4

    체크포인트 확인

    보류 중인 로컬 변경을 보고 커밋이나 발행 전에 멈춥니다.

주요 기능

  • 로컬 논문·글 편집
  • 관리 앱 상태 확인
  • 분리된 Git 체크포인트
  • 공개 피드 미리보기와 발행
  • 배포 상태와 출처 확인

데이터와 개인정보

새 기록은 기본적으로 비공개입니다. 토큰을 앱 데이터에 저장하지 않으며 시연 화면에는 정해진 설명용 기록만 사용합니다.

언어

  • Rust

인터페이스

기술 아이콘은 저장소에 포함된 범주 심볼이며, 실제 기술 이름을 함께 표시합니다.

Studio와의 관계

Studio는 조정 역할만 하며 보조 앱은 자체 데이터와 전체 작업 흐름을 계속 소유합니다.

현재 상태

로컬 개발 환경에서 작성, 저장소 체크포인트, 공개 미리보기, 피드 발행, 배포 확인, 관리 앱 기반 기능을 사용할 수 있습니다.

현재 한계

  • 배포용 macOS 서명과 공증은 아직 설정하지 않았습니다.
  • 일부 관리 앱 연결은 배포 전 검토가 더 필요합니다.

기술 메모

  • React와 TypeScript가 Tauri 데스크톱 UI를 표시합니다.
  • Rust 명령과 공통 패키지가 파일, Git, 발행 경계를 형식이 정해진 계약으로 유지합니다.
  • 비공개 저장소 URL은 공개하지 않습니다.

다음 단계

  • 서명된 배포 방식을 결정합니다.
  • 관리 동작을 늘리기 전에 앱 연결 호환성을 확인합니다.
