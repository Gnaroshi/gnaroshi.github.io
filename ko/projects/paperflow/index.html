PaperFlow

라이브러리 확인과 계획을 실제 쓰기 단계에서 분리해 컬렉션 이동과 중복 제안을 먼저 검토할 수 있게 합니다.

로컬에서 사용 가능macOS · CLI

한눈에 보기

대상
로컬 Zotero 논문 라이브러리를 관리하는 사람
주요 용도
라이브러리를 살펴보고 정리 계획을 만든 뒤 모든 제안을 확인해 적용 여부를 결정합니다.

정리 계획을 검토하는 흐름

  1. 1

    읽기 전용 스캔

    같은 읽기 전용 흐름으로 합성 라이브러리를 살펴봅니다.

  2. 2

    계획 만들기

    적용하지 않고 컬렉션 이동과 중복 그룹을 준비합니다.

  3. 3

    제안 확인

    쓰기가 가능한 동작 전에 범위와 항목을 확인합니다.

  4. 4

    적용 전에 멈추기

    시연 모드에서는 적용을 끄고 명시적 경계를 유지합니다.

주요 기능

  • Zotero Local API 읽기 전용 스캔
  • 정리·중복 계획
  • 시험 실행 보고서
  • 지원되는 쓰기 전 명시적 확인
  • 로컬 PDF 보관함 흐름

데이터와 개인정보

시연 모드는 실제 Zotero 라이브러리를 열지 않습니다. 일반 실행의 인증 정보는 Keychain에 두고 로그에서 가립니다.

기술 구성

언어

  • Python
  • Swift

인터페이스

  • SwiftUI

연결

  • Zotero Local API

기술 아이콘은 저장소에 포함된 범주 심볼이며, 실제 기술 이름을 함께 표시합니다.

현재 상태

스캔, 계획, 보고서, 가져오기 미리보기, 로컬 보관함 흐름이 로컬에서 작동합니다. Studio 전달 계약은 검토 중입니다.

현재 한계

  • 최종 패키지 앱과 화면 모양 확인이 남았습니다.
  • 쓰기가 가능한 흐름은 계속 수동 검토가 필요합니다.
기술 세부사항

개요

CLI가 Zotero 분석과 안전 규칙을 담당하고 SwiftUI 앱이 스캔, 계획, 보고서, 가져오기 검토 흐름을 보여 줍니다.

Studio와의 관계

Studio는 PaperFlow를 열거나 선택한 논문 전달을 미리 볼 수 있습니다. Zotero 접근과 적용 판단은 PaperFlow만 맡습니다.

기술 메모

  • Python이 정리 계획의 기준 구현입니다.
  • SwiftUI와 AppKit이 macOS 인터페이스를 제공합니다.
  • 라이브러리 메타데이터의 소유자는 Zotero입니다.

다음 단계

  • 패키지된 macOS 앱을 확인합니다.
  • 연결이 늘어도 적용 확인을 눈에 띄게 유지합니다.
