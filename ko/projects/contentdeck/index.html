ContentDeck

미디어 유형 확인과 자막, 구간 경계, 반복 상태를 하나의 집중된 재생 공간에 모읍니다.

로컬에서 사용 가능웹 · macOS

한눈에 보기

대상
지원 미디어의 짧은 구간을 연습하는 사람
주요 용도
사용 권한이 분명한 미디어를 열고 자막을 확인한 뒤 짧은 구간을 선택해 반복합니다.
제품 상태
로컬에서 사용 가능
지원 환경
웹 · macOS

개요

React 인터페이스가 웹과 Electron에서 작동합니다. 제한된 로컬 서비스가 미디어 해석을 맡고 원격 페이지는 Node와 셸에 접근하지 못합니다.

사용 흐름

짧은 구간 반복

사용 권한이 분명한 생성 로컬 클립의 짧은 구간을 연습합니다.

  1. 1

    미디어 열기

    네트워크 요청 없이 사용 권한이 분명한 로컬 테스트 클립을 엽니다.

  2. 2

    자막 확인

    재생 중 자막 트랙이 보이는지 확인합니다.

  3. 3

    16초 선택

    00:12–00:28 구간을 연습 범위로 정합니다.

  4. 4

    반복 켜기

    자막을 보면서 선택한 구간을 반복합니다.

주요 기능

  • 미디어 유형 확인
  • 자막 표시
  • 전체·구간 반복
  • 저장한 구간 맥락
  • 웹·Electron 모드

데이터와 개인정보

승인된 흐름은 합성 오디오가 있는 생성 로컬 클립을 씁니다. 상업 영상 프레임, 사용자 기록, 원격 URL, 인증 정보는 없습니다.

기술 아이콘은 저장소에 포함된 범주 심볼이며, 실제 기술 이름을 함께 표시합니다.

Studio와의 관계

Studio는 검증한 미디어 URL을 ContentDeck에서 열 수 있지만 재생과 자막 상태는 ContentDeck에 남습니다.

현재 상태

미디어 유형 확인과 전체·구간 반복, 자막, 웹 모드, Electron 모드가 로컬에서 구현되어 있습니다.

현재 한계

  • 패키지된 Electron 앱을 로컬에서 완전히 확인해야 합니다.
  • 미디어 제공 방식과 자막 메타데이터에 따라 가능한 동작이 달라집니다.

기술 메모

  • React와 TypeScript가 재생기 상태를 공유합니다.
  • Electron이 로컬 데스크톱 셸을 제공합니다.
  • Vite가 웹 렌더러를 빌드하고 제한된 로컬 서비스는 Fastify를 사용합니다.

다음 단계

  • 패키지된 Electron 앱을 확인합니다.
  • 미디어를 열 수 없는 경우와 자막 사용 가능 여부를 분명히 보여 줍니다.
