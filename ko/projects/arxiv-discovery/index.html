Arxiv Discovery

논문을 찾는 일과 다운로드·전달을 분리해 후보를 확인하는 단계를 눈에 보이게 합니다.

개요

현재 공개 기준은 로컬 Flask 검토 화면과 명령 흐름을 제공합니다. 더 큰 패키지 개편은 별도 작업으로 준비 중입니다.

사용 흐름

다운로드 전 후보 검토

합성 VLA 후보를 확인하고 PDF 다운로드나 쓰기 전에 멈춥니다.

  1. 1

    후보 찾기

    다운로드를 끈 최근 논문 목록을 엽니다.

  2. 2

    목록 좁히기

    현재 질문과 관련된 후보만 살펴봅니다.

  3. 3

    후보 하나 확인

    PDF 다운로드가 꺼진 상태로 선택한 메타데이터를 읽습니다.

  4. 4

    전달 미리보기

    PaperFlow에는 공개 메타데이터만 넘어가는지 확인합니다.

주요 기능

  • 최근 후보 목록
  • 다운로드 없는 시연 흐름
  • 후보 상세 확인
  • 공개 메타데이터만 쓰는 전달 미리보기

데이터와 개인정보

승인된 흐름은 합성 제목과 저자를 사용하고 네트워크 요청을 하지 않으며 PDF와 로컬 경로를 포함하지 않습니다.

기술 구성

언어

  • Python

프레임워크

  • Flask

인터페이스

  • Jinja

기술 아이콘은 저장소에 포함된 범주 심볼이며, 실제 기술 이름을 함께 표시합니다.

Studio와의 관계

호환성을 확인한 뒤 Studio에서 탐색 요청과 후보 전달 미리보기를 사용할 수 있습니다.

현재 상태

현재 공개 저장소는 로컬 검토 UI를 실행할 수 있습니다. 명시적 시연 모드는 같은 목록, 상세, 전달 상태를 재현합니다.

현재 한계

  • 새 패키지 구조는 아직 공개 기본 브랜치에 커밋되지 않았습니다.
  • 로컬 인터페이스의 전체 작업 흐름과 테마 검토가 더 필요합니다.

기술 메모

  • Python과 Flask가 로컬 검토 화면을 제공합니다.
  • Jinja가 목록, 상세, 전달 페이지를 표시합니다.
  • 공개 저장소만 연결하며 비공개 원본은 노출하지 않습니다.

다음 단계

  • 패키지 개편을 별도 변경으로 반영합니다.
  • 최종 CLI와 로컬 UI에서 다운로드 없음 동작을 확인합니다.
