# Localization Terminology

Use these terms consistently in Korean content and task copy. Global navigation and site-owned breadcrumb labels remain English in both locales by owner choice: Home, Research, Projects, Blog, Papers, About, Activity, Now, and Links. Blog replaces the previous public Writing label; private writing-workspace names do not change. Papers appears in both locales when public paper notes exist in either language, not as empty onboarding. Do not translate those stable navigation labels merely because the article is Korean.

| English | Korean | Notes |
| --- | --- | --- |
| Blog | 블로그 | The public navigation label stays `Blog`. |
| Papers | 논문 정리 | The public navigation label for `/papers/` stays `Papers` in both locales; the Korean page title is `논문 정리`. |
| Paper note | 논문 정리 | A written note about a paper, not a prescribed reading method. |
| Note Review | 노트 검토 | Review of evidence written in a note; never a claim of true understanding. |
| Review Result | 검토 결과 | A bounded result from one note or practice attempt. |
| Area to Revisit | 다시 볼 부분 | Prefer over `weak dimension`. |
| Activity Over Time | 기록의 변화 | Prefer over `score trend` or productivity language. |
| Activity | 활동 | Use for `/growth/` only when the public metric is eligible. |
| evidence of understanding | 이해를 뒷받침하는 기록 | May shorten to `이해의 근거` in compact labels. |
| Review due | 복습 예정 | Use `기한 지남` only when overdue. |
| Implementation attempt | 구현 시도 | |
| Reading Queue | 읽을 논문 | `읽기 목록` is acceptable in explanatory text. |
| current streak | 현재 연속 기록 | |
| longest streak | 최장 연속 기록 | |
| deep read | 깊이 읽기 | |
| source-only | 원문만 제공 | Content state, not a visible achievement. |

Internal component, field and route names may retain historical identifiers for compatibility. Do not restore reading-method instructions, numbered pass selectors or practice controls through renamed UI. Existing written notes and activity records remain preserved.

Do not translate proper nouns and canonical technical names such as GitHub, Astro, React, MDX, arXiv, model names, dataset names, paper titles, code identifiers, and formulas unless an official localized name is supplied.
